＋ 新增记忆（标准格式）

标准格式（不接受其它格式，保存时会校验）：
· 时间：2026 或 2026-08 或 2026-08-27
· 参与者：用中文顿号分隔，如 洛天依、洛天依（朋友）
· 主题：可选，从 美食/旅行/娱乐/爱好/学习/社交/回忆/健康/日程/日常/综合 中选择一个；留空自动归类
· 内容：一句话即可，2~1000 字，如「今天下午三点约好一起去公园散步」
